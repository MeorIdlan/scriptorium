# Scenes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Writers can split a chapter into scenes with cards (title, POV, location, status, summary), see and edit them beside the editor, reorder and move them, see them on the Map with a POV filter, and have the AI and export use them.

**Architecture:** A scene starts with an `<hr data-scene …>` marker inside the chapter's `contentHtml`, and the card's fields are attributes on that marker, so undo, history, milestones and moves keep text and card together. The server sanitizes markers, parses them with `htmlparser2` into a cached `Chapter.scenes` list on every save, and moves scenes with one endpoint that rewrites both chapters' HTML. The client reads scenes straight from the editor DOM for the Scenes tab.

**Tech Stack:** Express 4 + Mongoose 8 (ESM), `sanitize-html`, `htmlparser2@12.0.0`, React 18 + Vite 5 contentEditable editor, Node test runner (`node --test`) with `linkedom` on the client.

**Spec:** `docs/superpowers/specs/2026-10-11-scenes-design.md`

## Global Constraints

- Marker: `<hr data-scene="scn_<Date.now()>_<6 hex>" data-title data-pov data-location data-status data-summary>`; ids unique within a chapter.
- Limits: title 120, POV 60, location 80, summary 600 characters. Statuses `todo` | `draft` | `revise` | `done`; default `draft`. Labels `To do`, `Draft`, `Revise`, `Done`.
- A chapter with no markers is one implicit scene with no card; `Chapter.scenes` is `[]` for it. Text before the first marker is the opening scene (`id: null`), counted only when it has text.
- `Chapter.scenes` is rebuilt from `contentHtml` on every save that sets it, and never accepted from a client.
- Move endpoint: `POST /api/works/:workId/chapters/:chapterId/scenes/move` with `{ sceneId, toChapterId, toIndex }`; `sceneId` is a marker id or `"opening"`; `toIndex` counts the destination's scenes after removing the moved scene when it is the same chapter. No move merges two scenes.
- Snapshots before a move have note `Before moving a scene`.
- Context headings: `## This scene`, `## Scenes in this chapter`; scene list at most 30 lines, each at most 200 characters. Manifest keys `scene` (boolean) and `sceneList` (count). Hooks pass `scene`; editor-review and rekindler pass `sceneList`; polish-draft and beat-suggest pass neither.
- Export scene break: a centred `* * *` paragraph in PDF, DOCX and EPUB. Cards are never exported.
- Copy: hint "Add a scene break (Ctrl+Shift+Enter) to split this chapter into scenes."; remove confirm "Remove this scene break? The text joins the scene before it and this card is deleted."; after a move "Moved. History has the version from before the move."; Map empty state "No scene breaks in this chapter."; over-limit "<n> / <limit> characters. Shorten it to save."
- All commands run from `/home/meor/workspace/scriptorium`. Tests: `npm --prefix server test`, `npm --prefix client test`.
- Do not push. Commits end with the session's attribution lines.

## Review Focus

1. **Moving into or out of an older plain-text chapter** (only `content`, no `contentHtml`): its text must survive. `chapterHtml()` turns plain text into HTML first; covered in Task 2 and Task 4's E2E.
2. **Autosave racing a move:** a pending autosave of the pre-move HTML must not overwrite the moved result. The move response carries the new `content`/`contentHtml` so the client replaces the editor immediately (Task 10); the E2E saves, moves, then checks the chapter is unchanged after 6 s.
3. **Chrome putting the inserted `<hr>` inside the caret's `<div>`:** `liftMarker` moves it to the top level; unit-tested in Task 7 and checked in the browser in Task 8.
4. **Pasting a marker twice or pasting a bare `<hr>`:** the sanitizer gives duplicates and bare `hr`s new ids (Task 3 tests); the Scenes tab lists both.
5. **Polish on a chapter with markers:** markers are their own empty blocks, so Polish never targets them and applying changes keeps them (Task 7 test).

```js
// server/src/services/sceneMarkers.js
// Scenes live inside a chapter's HTML: each starts with a top-level
// <hr data-scene …> whose attributes hold the scene's card.
import { parseDocument } from 'htmlparser2';
import { randomBytes } from 'node:crypto';
import { countWords } from './wordCountService.js';

export const SCENE_STATUSES = ['todo', 'draft', 'revise', 'done'];
export const SCENE_LIMITS = { title: 120, pov: 60, location: 80, summary: 600 };
export const SCENE_ATTRS = { title: 'data-title', pov: 'data-pov', location: 'data-location', summary: 'data-summary' };

const BLOCK_TAGS = new Set(['div', 'p', 'h1', 'h2', 'h3', 'blockquote']);

export function newSceneId(now = Date.now()) {
  return `scn_${now}_${randomBytes(3).toString('hex')}`;
}

const isTag = (node) => node.type === 'tag';
export const isMarker = (node) => isTag(node) && node.name === 'hr' && Boolean(node.attribs['data-scene']);

// Same model as the client's blockPieces: a nested block or <hr> ends a line
function blockText(nodes) {
  let text = '';
  let closed = false;
  const breakAfter = () => {
    if (closed && text && !text.endsWith('\n')) text += '\n';
    closed = false;
  };
  const walk = (node, nested) => {
    if (node.type === 'text') {
      if (node.data) breakAfter();
      text += node.data;
      return;
    }
    if (!isTag(node)) return;
    if (node.name === 'br') {
      breakAfter();
      text += '\n';
      return;
    }
    if (node.name === 'hr') {
      closed = true;
      return;
    }
    const block = BLOCK_TAGS.has(node.name);
    if (block) {
      closed = false;
      if (text && !text.endsWith('\n')) text += '\n';
    }
    for (const child of node.children) walk(child, true);
    if (nested && block) closed = true;
  };
  for (const node of nodes) walk(node, false);
  return text;
}

// Top-level blocks: each block element (or <hr>) alone, runs of inline nodes together
export function topBlocks(nodes) {
  const groups = [];
  let run = null;
  for (const node of nodes) {
    if (isTag(node) && (BLOCK_TAGS.has(node.name) || node.name === 'hr')) {
      run = null;
      groups.push([node]);
    } else {
      if (!run) {
        run = [];
        groups.push(run);
      }
      run.push(node);
    }
  }
  return groups.map(blockText);
}

// [{ marker, nodes }]; the first entry is the opening (marker null)
export function splitTop(html) {
  const doc = parseDocument(html || '', { withStartIndices: true, withEndIndices: true });
  const segments = [{ marker: null, nodes: [] }];
  for (const node of doc.children) {
    if (isMarker(node)) segments.push({ marker: node, nodes: [] });
    else segments[segments.length - 1].nodes.push(node);
  }
  return segments;
}

export function cardOf(marker) {
  if (!marker) return { id: null, title: '', pov: '', location: '', status: 'draft', summary: '' };
  const a = marker.attribs;
  const card = { id: a['data-scene'] };
  for (const [field, attr] of Object.entries(SCENE_ATTRS)) card[field] = a[attr] || '';
  card.status = SCENE_STATUSES.includes(a['data-status']) ? a['data-status'] : 'draft';
  return card;
}

export function paragraphsOf(nodes) {
  return topBlocks(nodes)
    .flatMap((block) => block.split(/\n\s*\n/))
    .map((p) => p.trim())
    .filter(Boolean);
}

export function parseScenes(html) {
  const segments = splitTop(html);
  const hasMarkers = segments.length > 1;
  return segments
    .map((seg) => {
      const paragraphs = paragraphsOf(seg.nodes);
      const text = paragraphs.join('\n');
      return { ...cardOf(seg.marker), paragraphs, text, wordCount: countWords(text) };
    })
    .filter((scene, i) => i > 0 || !hasMarkers || scene.text !== '');
}

export function sceneSummaries(html) {
  const scenes = parseScenes(html);
  if (!scenes.some((s) => s.id)) return [];
  return scenes.map(({ id, title, pov, location, status, summary, wordCount }) => ({
    id,
    title,
    pov,
    location,
    status,
    summary,
    wordCount,
  }));
}

export function chapterText(html) {
  return parseScenes(html)
    .map((s) => s.text)
    .filter(Boolean)
    .join('\n\n');
}

// Paragraphs per scene for export; older chapters only have plain text
export function exportScenes({ content, contentHtml }) {
  if (typeof contentHtml === 'string' && contentHtml.trim()) {
    return parseScenes(contentHtml)
      .map((s) => s.paragraphs)
      .filter((p) => p.length > 0);
  }
  const paragraphs = (content || '')
    .split(/\n\n+/)
    .map((p) => p.trim())
    .filter(Boolean);
  return paragraphs.length ? [paragraphs] : [];
}
```

```js
function escapeHtml(text) {
  return String(text).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
}

// Chapters saved before HTML storage only have plain text; the editor loads
// that text with innerText, which turns newlines into <br>
export function chapterHtml({ content, contentHtml } = {}) {
  if (typeof contentHtml === 'string' && contentHtml.trim()) return contentHtml;
  if (!content) return '';
  return content.split('\n').map(escapeHtml).join('<br />');
}

function sliceOf(html, nodes) {
  if (nodes.length === 0) return '';
  return html.slice(nodes[0].startIndex, nodes[nodes.length - 1].endIndex + 1);
}

// { prefix, scenes: [{ id, marker, body }] } — an opening without text is
// kept as a prefix, not a scene (so an empty chapter has no scenes)
function sceneSegments(html) {
  const segments = splitTop(html).map((seg) => ({
    id: seg.marker ? seg.marker.attribs['data-scene'] : null,
    marker: seg.marker ? sliceOf(html, [seg.marker]) : '',
    body: sliceOf(html, seg.nodes),
    hasText: paragraphsOf(seg.nodes).length > 0,
  }));
  if (!segments[0].hasText) return { prefix: segments[0].body, scenes: segments.slice(1) };
  return { prefix: '', scenes: segments };
}

// A card-less scene anywhere but first would merge into the scene before it
function keepSeparate(scenes) {
  scenes.forEach((scene, i) => {
    if (i > 0 && !scene.marker) {
      scene.id = newSceneId();
      scene.marker = `<hr data-scene="${scene.id}" data-status="draft" />`;
    }
  });
}

const joinSegments = ({ prefix, scenes }) => prefix + scenes.map((s) => s.marker + s.body).join('');

export function moveScene({ srcHtml, dstHtml, sceneId, toIndex, sameChapter }) {
  const src = sceneSegments(srcHtml || '');
  const from = src.scenes.findIndex((s) => (sceneId === 'opening' ? s.id === null : s.id === sceneId));
  if (from < 0) return { error: 'NOT_FOUND' };
  const dst = sameChapter ? src : sceneSegments(dstHtml || '');
  const [moved] = src.scenes.splice(from, 1);
  if (!Number.isInteger(toIndex) || toIndex < 0 || toIndex > dst.scenes.length) return { error: 'INVALID_INDEX' };
  if (sameChapter && toIndex === from) return { error: 'NO_CHANGE' };
  dst.scenes.splice(toIndex, 0, moved);
  keepSeparate(src.scenes);
  if (!sameChapter) keepSeparate(dst.scenes);
  const newSrc = joinSegments(src);
  return { srcHtml: newSrc, dstHtml: sameChapter ? newSrc : joinSegments(dst) };
}
```

```js
import sanitizeHtml from 'sanitize-html';
import { SCENE_ATTRS, SCENE_LIMITS, SCENE_STATUSES, newSceneId } from './sceneMarkers.js';

// Chapter HTML comes from a contentEditable driven by document.execCommand,
// which emits <b>/<i>/<u>, <font face size>, and text-align on block elements.
// <hr data-scene …> marks the start of a scene; its attributes are the card.
const OPTIONS = {
  allowedTags: ['p', 'div', 'br', 'b', 'strong', 'i', 'em', 'u', 'span', 'font', 'h1', 'h2', 'h3', 'blockquote', 'hr'],
  allowedAttributes: {
    '*': ['style', 'align'],
    font: ['face', 'size'],
    hr: ['data-scene', ...Object.values(SCENE_ATTRS), 'data-status'],
  },
  allowedStyles: {
    '*': {
      'text-align': [/^(left|right|center|justify|start|end)$/],
      'font-family': [/^[\w\s,'"-]+$/],
      'font-size': [/^\d+(\.\d+)?(px|pt|em|rem|%)$/, /^(x{0,2}-small|small|medium|large|x{0,3}-large)$/],
      'font-weight': [/^(bold|normal|\d{3})$/],
      'font-style': [/^(italic|normal)$/],
      'text-decoration': [/^(underline|none)$/],
    },
  },
  allowedSchemes: [],
};

const SAFE_ID = /^[\w-]{1,64}$/;

// Ids only need to be unique within one chapter, so each call tracks its own
function sceneMarker() {
  const seen = new Set();
  return (tagName, attribs) => {
    let id = typeof attribs['data-scene'] === 'string' ? attribs['data-scene'].trim() : '';
    if (!SAFE_ID.test(id) || seen.has(id)) id = newSceneId();
    seen.add(id);
    const out = { 'data-scene': id };
    for (const [field, attr] of Object.entries(SCENE_ATTRS)) {
      const value = typeof attribs[attr] === 'string' ? attribs[attr].trim().slice(0, SCENE_LIMITS[field]).trim() : '';
      if (value) out[attr] = value;
    }
    out['data-status'] = SCENE_STATUSES.includes(attribs['data-status']) ? attribs['data-status'] : 'draft';
    return { tagName: 'hr', attribs: out };
  };
}

export function sanitizeChapterHtml(html) {
  if (typeof html !== 'string') return '';
  return sanitizeHtml(html, { ...OPTIONS, transformTags: { hr: sceneMarker() } });
}
```

```js
router.post('/:chapterId/scenes/move', async (req, res, next) => {
  try {
    const { workId, chapterId } = req.params;
    const { sceneId, toChapterId, toIndex } = req.body || {};
    const invalid = (field, message) => next(Object.assign(httpError(400, 'INVALID_FIELD', message), { field }));
    if (typeof sceneId !== 'string' || !sceneId.trim()) return invalid('sceneId', 'sceneId is required');
    if (typeof toChapterId !== 'string' || !toChapterId) return invalid('toChapterId', 'toChapterId is required');
    if (!Number.isInteger(toIndex) || toIndex < 0) return invalid('toIndex', 'toIndex must be a whole number of 0 or more');

    const source = await Chapter.findOne({ _id: chapterId, workId });
    if (!source) return next(httpError(404, 'NOT_FOUND', 'Chapter not found'));
    const sameChapter = toChapterId === chapterId;
    const target = sameChapter ? source : await Chapter.findOne({ _id: toChapterId, workId });
    if (!target) return invalid('toChapterId', 'toChapterId must be a chapter of this work');

    const result = moveScene({
      srcHtml: chapterHtml(source),
      dstHtml: chapterHtml(target),
      sceneId: sceneId.trim(),
      toIndex,
      sameChapter,
    });
    if (result.error === 'NOT_FOUND') return next(httpError(404, 'SCENE_NOT_FOUND', 'Scene not found'));
    if (result.error === 'INVALID_INDEX') return invalid('toIndex', 'toIndex is past the end of the chapter');
    if (result.error === 'NO_CHANGE') return res.json({ chapters: [] });

    const now = new Date().toISOString();
    const changed = sameChapter ? [source] : [target, source];
    // Never move without a way back
    for (const chapter of changed) {
      await takeAutoSnapshot(chapter, now, { note: 'Before moving a scene' });
    }

    // Destination first: a failure in between duplicates the scene, never loses it
    const updatedTarget = await writeMovedChapter(target, result.dstHtml, now);
    let updatedSource = updatedTarget;
    if (!sameChapter) {
      try {
        updatedSource = await writeMovedChapter(source, result.srcHtml, now);
      } catch (err) {
        console.error('Scene move source write failed:', err);
        return next(
          httpError(500, 'MOVE_INCOMPLETE', `The scene was copied to "${target.title}" but not removed from "${source.title}".`)
        );
      }
    }

    const updated = sameChapter ? [updatedTarget] : [updatedTarget, updatedSource];
    for (const chapter of updated) {
      try {
        await scan(workId, chapter._id, chapter.content);
      } catch (scanErr) {
        console.error('Consistency scan error:', scanErr);
      }
    }
    try {
      await recalculate(workId);
    } catch (err) {
      console.error('Word count recalculation failed:', err);
    }

    res.json({ chapters: updated.map(chapterResponse) });
  } catch (err) {
    next(err);
  }
});
```

```js
const SCENE_LINE_MAX = 200;
export const MAX_SCENE_LINES = 30;

const oneLine = (text) => text.replace(/\s+/g, ' ').trim();

// The card of the scene the writer is working in
function sceneSection(scene) {
  if (!scene || ![scene.title, scene.pov, scene.location, scene.summary].some(nonBlank)) return '';
  const lines = [['Title', scene.title], ['POV', scene.pov], ['Location', scene.location], ['Status', scene.status], ['Summary', scene.summary]]
    .filter(([, v]) => nonBlank(v))
    .map(([k, v]) => `${k}: ${oneLine(v)}`);
  return `## This scene\n${lines.join('\n')}`;
}

function sceneListSection(scenes) {
  const list = (scenes || []).filter((s) => s && typeof s === 'object');
  if (!list.some((s) => s.id)) return { text: '', count: 0 };
  const lines = list.slice(0, MAX_SCENE_LINES).map((s, i) => {
    let line = nonBlank(s.title) ? oneLine(s.title) : `Scene ${i + 1}`;
    if (nonBlank(s.pov)) line += ` (${oneLine(s.pov)})`;
    if (nonBlank(s.summary)) line += `: ${oneLine(s.summary)}`;
    return `- ${clip(line, SCENE_LINE_MAX)}`;
  });
  return { text: `## Scenes in this chapter\n${lines.join('\n')}`, count: lines.length };
}
```

```js
// Scenes inside the editor: each starts with a top-level
// <hr data-scene …> whose attributes hold the scene's card.
import { getBlocks, blockEndPoint, topLevelNode, rememberedCaret } from './editorBlocks.js';
import { countWords } from './wordCount.js';

export const SCENE_STATUSES = ['todo', 'draft', 'revise', 'done'];
export const STATUS_LABELS = { todo: 'To do', draft: 'Draft', revise: 'Revise', done: 'Done' };
export const SCENE_LIMITS = { title: 120, pov: 60, location: 80, summary: 600 };
const ATTRS = { title: 'data-title', pov: 'data-pov', location: 'data-location', summary: 'data-summary' };

export function newSceneId(now = Date.now()) {
  const bytes = globalThis.crypto.getRandomValues(new Uint8Array(3));
  return `scn_${now}_${Array.from(bytes, (b) => b.toString(16).padStart(2, '0')).join('')}`;
}

export const isMarker = (node) => node?.nodeType === 1 && node.tagName === 'HR' && node.hasAttribute('data-scene');

function cardOf(marker) {
  if (!marker) return { id: null, title: '', pov: '', location: '', status: 'draft', summary: '' };
  const card = { id: marker.getAttribute('data-scene') };
  for (const [field, attr] of Object.entries(ATTRS)) card[field] = marker.getAttribute(attr) || '';
  const status = marker.getAttribute('data-status');
  card.status = SCENE_STATUSES.includes(status) ? status : 'draft';
  return card;
}

export function sceneList(root) {
  const segments = [{ marker: null, blocks: [] }];
  for (const block of getBlocks(root)) {
    if (block.nodes.length === 1 && isMarker(block.nodes[0])) segments.push({ marker: block.nodes[0], blocks: [] });
    else segments[segments.length - 1].blocks.push(block);
  }
  const hasMarkers = segments.length > 1;
  return segments
    .map((seg) => {
      const text = seg.blocks.map((b) => b.text).join('\n').trim();
      return { ...cardOf(seg.marker), marker: seg.marker, blocks: seg.blocks, text, wordCount: countWords(text) };
    })
    .filter((scene, i) => i > 0 || !hasMarkers || scene.text !== '')
    .map((scene, index) => ({ ...scene, index }));
}

// Walks top-level nodes only, so it is cheap enough for every caret move
export function sceneAtNode(root, node, list = sceneList(root)) {
  if (!node || node.parentNode !== root) return -1;
  let marker = null;
  for (const child of root.childNodes) {
    if (isMarker(child)) marker = child;
    if (child === node) break;
  }
  const index = list.findIndex((s) => s.marker === marker);
  return index >= 0 ? index : 0;
}

export function sceneAtCaret(root) {
  if (!root) return null;
  const list = sceneList(root);
  if (!list.some((s) => s.id)) return null;
  const index = sceneAtNode(root, rememberedCaret(root), list);
  return index >= 0 ? list[index] : null;
}

export function sceneLabel(scene) {
  return scene.title?.trim() || `Scene ${scene.index + 1}`;
}

const formatCount = (n) => n.toLocaleString('en-US');

export function sceneFieldError(field, value) {
  const length = (value || '').trim().length;
  const limit = SCENE_LIMITS[field];
  return length > limit ? `${formatCount(length)} / ${formatCount(limit)} characters. Shorten it to save.` : '';
}

const escapeAttr = (v) => String(v).replace(/&/g, '&amp;').replace(/"/g, '&quot;').replace(/</g, '&lt;').replace(/>/g, '&gt;');

export function markerHtml({ id, status = 'draft', ...fields }) {
  const attrs = [`data-scene="${escapeAttr(id)}"`];
  for (const [field, attr] of Object.entries(ATTRS)) {
    const value = (fields[field] || '').trim();
    if (value) attrs.push(`${attr}="${escapeAttr(value)}"`);
  }
  attrs.push(`data-status="${SCENE_STATUSES.includes(status) ? status : 'draft'}"`);
  attrs.push('contenteditable="false"');
  return `<hr ${attrs.join(' ')}>`;
}

export function applyCard(marker, fields) {
  for (const [field, attr] of Object.entries(ATTRS)) {
    const value = (fields[field] || '').trim();
    if (value) marker.setAttribute(attr, value);
    else marker.removeAttribute(attr);
  }
  marker.setAttribute('data-status', SCENE_STATUSES.includes(fields.status) ? fields.status : 'draft');
}

// linkedom (tests) and the browser each have their own Event class
const fireInput = (root) => {
  const EventClass = root.ownerDocument.defaultView?.Event || globalThis.Event;
  root.dispatchEvent(new EventClass('input', { bubbles: true }));
};

// Not in the browser's undo history; the writer can edit the card again
export function writeSceneCard(root, index, fields) {
  const scene = sceneList(root)[index];
  if (!scene) return false;
  let marker = scene.marker;
  if (!marker) {
    marker = root.ownerDocument.createElement('hr');
    marker.setAttribute('data-scene', newSceneId());
    marker.setAttribute('contenteditable', 'false');
    root.insertBefore(marker, root.firstChild);
  }
  applyCard(marker, fields);
  fireInput(root);
  return true;
}

export function lockMarkers(root) {
  let changed = 0;
  for (const child of root.children) {
    if (isMarker(child) && child.getAttribute('contenteditable') !== 'false') {
      child.setAttribute('contenteditable', 'false');
      changed += 1;
    }
  }
  return changed;
}

// Chrome can put inserted HTML inside the caret's block; a marker only
// splits scenes at the top level
export function liftMarker(root, marker) {
  const top = topLevelNode(root, marker);
  if (!top || top === marker) return;
  const rest = [];
  for (let n = marker.nextSibling; n; n = n.nextSibling) rest.push(n);
  root.insertBefore(marker, top.nextSibling);
  if (rest.length) {
    const after = root.ownerDocument.createElement(top.tagName.toLowerCase());
    rest.forEach((n) => after.appendChild(n));
    if (after.textContent.trim() || after.querySelector('br')) root.insertBefore(after, marker.nextSibling);
  }
}

// Positions in a destination chapter; `moving` is the scene's own place when
// the destination is its own chapter (toIndex then counts without it)
export function positionOptions(destScenes, moving = null) {
  const rest = destScenes.filter((s) => !moving || s.index !== moving.index);
  const options = [{ label: 'At the start', toIndex: 0 }];
  rest.forEach((scene, pos) => {
    if (pos < rest.length - 1) options.push({ label: `After: ${sceneLabel(scene)}`, toIndex: pos + 1 });
  });
  if (rest.length > 0) options.push({ label: 'At the end', toIndex: rest.length });
  return moving ? options.filter((o) => o.toIndex !== moving.index) : options;
}
```

```js
// Top-level point after the caret's block (or its line, in a legacy
// plain-text run), so the marker never lands inside a paragraph
export function afterBlockPoint(root, caretNode) {
  const blocks = getBlocks(root);
  if (blocks.length === 0) return { node: root, offset: 0 };
  const block = (caretNode && blocks.find((b) => b.nodes.includes(caretNode))) || blocks[blocks.length - 1];
  if (block.nodes.length === 1 && block.nodes[0].nodeType === 1) {
    return { node: root, offset: [...root.childNodes].indexOf(block.nodes[0]) + 1 };
  }
  return blockEndPoint(root, caretNode);
}

function select(doc, setup) {
  const range = doc.createRange();
  setup(range);
  const selection = doc.getSelection();
  selection.removeAllRanges();
  selection.addRange(range);
}

// execCommand keeps the break in the browser's undo history and fires input
export function insertSceneBreak(root, caretNode) {
  const doc = root.ownerDocument;
  const point = afterBlockPoint(root, caretNode);
  root.focus();
  select(doc, (r) => {
    r.setStart(point.node, point.offset);
    r.collapse(true);
  });
  const id = newSceneId();
  const ok = doc.execCommand('insertHTML', false, `${markerHtml({ id })}<div><br></div>`);
  const marker = [...root.querySelectorAll('hr')].find((h) => h.getAttribute('data-scene') === id);
  if (!marker) return false;
  if (marker.parentNode !== root) liftMarker(root, marker);
  lockMarkers(root);
  const next = marker.nextSibling;
  if (next) {
    select(doc, (r) => {
      r.setStart(next, 0);
      r.collapse(true);
    });
  }
  return ok;
}

export function removeSceneBreak(root, marker) {
  if (!marker || marker.parentNode !== root) return false;
  const doc = root.ownerDocument;
  root.focus();
  select(doc, (r) => r.selectNode(marker));
  doc.execCommand('delete');
  // Fallback when the browser refuses to delete a non-editable node
  if (marker.parentNode) {
    marker.remove();
    fireInput(root);
  }
  return true;
}

export function scrollToScene(root, scene) {
  if (!scene) return;
  const doc = root.ownerDocument;
  (scene.marker || root).scrollIntoView?.({ block: 'start', behavior: 'smooth' });
  root.focus();
  const first = scene.blocks[0]?.nodes[0];
  select(doc, (r) => {
    if (first) r.setStart(first, 0);
    else r.setStart(root, scene.marker ? [...root.childNodes].indexOf(scene.marker) + 1 : 0);
    r.collapse(true);
  });
}
```

```jsx
import { useEffect, useRef, useState } from 'react';
import { useEditor } from '../../context/EditorContext.jsx';
import { useActiveWork } from '../../context/ActiveWorkContext.jsx';
import { rememberedCaret } from '../../utils/editorBlocks.js';
import { sceneList, sceneAtNode, writeSceneCard, removeSceneBreak, scrollToScene } from '../../utils/scenes.js';
import SceneRow from './SceneRow.jsx';

const editorRoot = () => document.querySelector('.editor');
const names = (list) => (list || []).map((e) => e?.name).filter((n) => typeof n === 'string' && n.trim());

export default function ScenesTab({ workId }) {
  const { state: editorState } = useEditor();
  const { state: workState } = useActiveWork();
  const [scenes, setScenes] = useState([]);
  const [current, setCurrent] = useState(-1);
  const [errors, setErrors] = useState({});
  const listRef = useRef([]);

  // The editor DOM is the source; refresh shortly after typing stops
  useEffect(() => {
    const timer = setTimeout(() => {
      const root = editorRoot();
      const list = root ? sceneList(root) : [];
      listRef.current = list;
      setScenes(list);
      if (root) setCurrent(sceneAtNode(root, rememberedCaret(root), list));
    }, 300);
    return () => clearTimeout(timer);
  }, [editorState.html, editorState.chapterId]);

  useEffect(() => {
    function onSelectionChange() {
      const root = editorRoot();
      if (root) setCurrent(sceneAtNode(root, rememberedCaret(root), listRef.current));
    }
    document.addEventListener('selectionchange', onSelectionChange);
    return () => document.removeEventListener('selectionchange', onSelectionChange);
  }, []);

  const withRoot = (key, fn) => {
    const root = editorRoot();
    if (!root) {
      setErrors((e) => ({ ...e, [key]: 'Open a chapter first.' }));
      return;
    }
    try {
      fn(root);
      setErrors((e) => ({ ...e, [key]: '' }));
    } catch (err) {
      setErrors((e) => ({ ...e, [key]: err.message || 'Something went wrong.' }));
    }
  };

  if (!editorState.chapterId) return <p className="scenes-empty">Open a chapter to see its scenes.</p>;

  const hasMarkers = scenes.some((s) => s.id);
  if (!hasMarkers) {
    return (
      <div className="scenes-tab">
        <ul className="scene-list">
          <li className="scene-row">
            <span className="scene-row-title">Whole chapter</span>
            <span className="scene-row-words">{(scenes[0]?.wordCount || 0).toLocaleString('en-US')} words</span>
          </li>
        </ul>
        <p className="scenes-hint">Add a scene break (Ctrl+Shift+Enter) to split this chapter into scenes.</p>
      </div>
    );
  }

  const characters = names(workState.codex?.characters);
  const places = names(workState.codex?.places);

  return (
    <div className="scenes-tab">
      <ul className="scene-list">
        {scenes.map((scene) => {
          const key = scene.id || 'opening';
          return (
            <SceneRow
              key={key}
              scene={scene}
              current={scene.index === current}
              characters={characters}
              places={places}
              error={errors[key]}
              onJump={() => withRoot(key, (root) => scrollToScene(root, sceneList(root)[scene.index]))}
              onSave={(fields) => withRoot(key, (root) => writeSceneCard(root, scene.index, fields))}
              onRemove={() => withRoot(key, (root) => removeSceneBreak(root, sceneList(root)[scene.index]?.marker))}
            />
          );
        })}
      </ul>
    </div>
  );
}
```

```js
export function moveSceneRequest(api, workId, { chapterId, scene, toChapterId, toIndex }) {
  return api.post(`/works/${workId}/chapters/${chapterId}/scenes/move`, {

// Another chapter's scenes come from the chapter list; a chapter without

export function destinationScenes(chapter) {
  const stored = Array.isArray(chapter?.scenes) ? chapter.scenes : [];
```

```js
const povKey = (pov) => pov.trim().toLowerCase();
const hasPov = (scene) => scene && typeof scene.pov === 'string' && scene.pov.trim() !== '';

export function povOptions(chapters) {
  const seen = new Map();
  for (const chapter of chapters || []) {
    for (const scene of chapter.scenes || []) {
      if (hasPov(scene) && !seen.has(povKey(scene.pov))) seen.set(povKey(scene.pov), scene.pov.trim());
    }
  }
  return [...seen.values()];
}

export function scenesForPov(chapter, pov) {
  const list = (chapter?.scenes || []).map((scene, index) => (scene ? { ...scene, index } : null)).filter(Boolean);
  if (!pov) return list;
  return list.filter((s) => hasPov(s) && povKey(s.pov) === povKey(pov));
}
```
